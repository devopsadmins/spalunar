# Prompt para Lovable.dev — Redesign SPA LUNAR

Use este prompt no [lovable.dev](https://lovable.dev) para explorar variações visuais do site spalunar.com.br.

---

## Versão 1: Modern Wellness Theme (Minimalista + Wellness)

```
Você é um designer UI/UX especializado em sites de bem-estar e clínicas estéticas.

Crie uma interface de homepage moderna para "SPA LUNAR" — uma clínica de estética e bem-estar.

**Contexto:**
- Clínica estética focada em atendimento personalizado
- Serviços principais: Corrente Russa, Criolipolise, Detox Corporal, Drenagens Linfáticas
- Público: mulheres 25-55 anos buscando bem-estar e resultados estéticos
- Domínio: spalunar.com.br

**Design Atual (Referência):**
- Cores: Laranja vibrante (#ff6b35), Teal/Verde (#00a896), Azul escuro (#08111b)
- Tipografia: Manrope (corpo), Outfit (headings)
- Estilo: Dark modern com gradientes e efeitos ambient
- Layout: Hero com CTA, cards de serviços, navegação horizontal

**Solicito uma NOVA APARÊNCIA com as seguintes características:**

### Pilares do Design
1. **Atmosfera**: Elegante, calmo, premium (menos "gaming", mais "spa luxury")
2. **Cores**: Paleta more neutral com acentos sofisticados
   - Opção: Palette Minimalist Cream/Rose/Sage
   - Ou: Palette Modern Luxury (Charcoal/Gold/Cream)
3. **Tipografia**: Manter Manrope + Outfit, mas explorar weights diferentes
4. **Components**: 
   - Hero section com imagem central (retrato, background subtle)
   - Seção "Serviços" com cards em grid (3-4 colunas)
   - Cada card com: ícone/imagem + título + descrição curta + "Saiba Mais"
   - Testimonials seção ou "Por Que SPA LUNAR" seção
   - Footer limpo com links e CTA secundário

### Requisitos Técnicos
- Responsivo (mobile-first)
- Acessibilidade WCAG 2.1 AA mínimo
- Sem animações pesadas (focus em UX)
- Estrutura compatível com Astro Framework
- Dados dinâmicos: title, meta_description, services array, images

### Entrega Esperada
Crie um protótipo interativo de:
1. Homepage hero + navigation
2. Seção serviços (mínimo 4 cards)
3. Seção CTA secundária ou testimonials
4. Footer

Export code como React/Preact components (compatível com Astro).

Priorize elegância e usabilidade sobre efeitos visuais.
```

Design a bold, contemporary homepage for "SPA LUNAR" — an aesthetic wellness clinic in Brazil.

  - Option A: Deep Navy (#1a1f2e) + Coral (#ef6a4a) + Cream (#faf9f6)
  - Option B: Black (#0a0a0a) + Lime/Neon Green (#b3ff00) + White (#ffffff)
  - Option C: Your creative choice — justify it
- **Typography**: Bold, confident headings; elegant body copy
  - Consider: pairing serif + sans-serif
- **Hero Section**: 
  - Large, impactful headline
  - Minimal but striking imagery or pattern
  - Single CTA button with micro-interaction
- **Services Grid**: 
  - 2-3 cards per row (adapts to mobile)
  - Each card: icon + service name + short description
- **Additional Sections**:
  - "Why Choose Us" with benefits/pillars
  - "Book Appointment" CTA section
- **Aesthetic**: Modern salon/spa vibes but edgy (not soft/pastel)

**Deliverables**:
- Interactive Figma-like prototype
- Responsive layout (375px / 1200px breakpoints)
- React components exportable to Astro

Keep it bold. Make it memorable.

- Ambient glow effects

## Dicas para Usar

1. **Copiar e colar um dos prompts acima** direto em um novo projeto no lovable.dev
2. **Adaptar cores/descrições** conforme sua preferência
3. **Fazer upload de imagens** do site atual (hero image, service images) para mais contexto visual
4. **Solicitar exportação em formato React** — Astro consegue usar componentes React nativamente
5. **Iterar**: Gerar múltiplas variações e pedir refinamentos ("mais minimalista", "mais cores quentes", etc.)
