# Onboarding

## Primeiros passos

1. Instalar Python 3.12+ e Node 22+.
2. Criar venv e instalar requirements.
3. Rodar crawler para gerar output/.
4. Instalar dependencias Node e rodar frontend Astro.

## Comandos uteis

- python main.py --use-playwright
- npm install
- npm run dev
- npm run build
