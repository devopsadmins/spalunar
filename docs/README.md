# Documentacao do Produto

Este diretorio segue o modelo obrigatorio do projeto0 para rastreabilidade de arquitetura, operacao, API e compliance.

## Estrutura

- adr/: registros de decisoes arquiteturais
- api/: contratos OpenAPI
- privacy/: inventario de dados pessoais e bases legais
- post-mortems/: analises de incidentes
- slo/: SLOs e error budget
- sbom/: politica e artefatos de supply chain
- infra/: mapas e convencoes operacionais
- skills/: catalogo local de skills e automacoes
- templates/: modelos de documentos
